GOKL GAME WORKS 한글패치 설치기 v0.6.1

패치 파일, 원본 게임, 저장 위치를 선택하면 한글패치를 적용하는 Windows 64비트용 프로그램입니다.

원본 파일과 폴더를 보존하며, 패치된 결과를 새 파일 또는 폴더로 저장합니다. 게임과 한글패치 데이터는 포함하지 않습니다.

다운로드

이 저장소의 Releases에서 GOKL_GAME_WORKS_Patch_Installer_v0.6.1_Windows_x64.zip을 다운로드하세요.

GitHub에서 자동으로 제공하는 Source code 압축파일은 소스 코드입니다. 실행하려면 별도로 첨부된 Windows용 ZIP을 받으세요.

ZIP 전체를 압축 해제하고 GOKL 한글패치 설치기.exe를 실행합니다. Python이나 xdelta를 별도로 설치할 필요가 없습니다.

사용 방법

1. 패치 파일: 제작자에게 별도로 받은 패치를 선택합니다.
2. 원본 게임: 패치 안내에 지정된 ROM·ISO·BIN 파일 또는 게임 폴더를 선택합니다.
3. 저장 위치: 패치된 결과를 받을 폴더를 선택합니다.
4. 게임과 에뮬레이터를 종료하고 한글패치 적용을 누릅니다.

프로그램이 패치 형식과 결과 이름을 자동으로 판단합니다. 예를 들어 Game_Korean.iso 또는 Game_Korean 폴더가 만들어집니다. 같은 이름의 결과가 이미 있으면 _2, _3 등을 붙여 기존 결과도 보존합니다.

폴더형 GOKL 패치는 원본 선택 버튼에서 게임 폴더 또는 PS3 ISO 파일을 선택할 수 있습니다. 원본이 폴더일 때 저장 위치는 해당 원본 폴더 밖으로 지정하세요.

지원 형식

- GOKL 파일형 (.goklpatch): ROM·ISO·BIN 파일에서 새 결과 파일 생성
- GOKL 폴더형 (.goklpatch): 게임 폴더에서 새 패치된 게임 폴더 생성
- GOKL 폴더형 + PS3 ISO: 복호화된 PS3 ISO9660 이미지를 새 폴더로 추출하고 패치 적용
- xdelta/VCDIFF (.xdelta, .xdelta3, .vcdiff, .delta): 내장 xdelta3로 새 결과 파일 생성
- IPS, IPS32, BPS, UPS, PPF 1/2/3: 원본 파일에 해당 형식의 패치를 적용해 새 파일 생성

확장자뿐 아니라 파일 내부의 형식도 확인합니다. 확장자만 바꾸면 다른 패치 형식으로 변환되는 것은 아닙니다.

추가 기능

추가 기능 버튼을 누르면 복구와 작업 기록을 확인할 수 있습니다.

- 복구된 사본 만들기: 같은 세 입력칸에서 패치와 패치된 게임을 선택합니다. GOKL, UPS, 복원 데이터가 있는 PPF3를 지원하며 _Restored 결과를 새로 저장합니다.
- 결과 폴더 열기: 완료된 결과의 저장 위치를 엽니다.
- 작업 기록: 저장 위치, 검증 결과, 도구 안내를 확인합니다.

xdelta·BPS·IPS는 동일한 패치로 역방향 복원할 수 없습니다. 보관한 원본을 사용하세요.

검증과 지원 범위

- GOKL은 지정된 원본과 결과의 크기·SHA-256을 검사합니다.
- BPS·UPS는 패치·원본·결과의 CRC32를 검사합니다.
- IPS·IPS32는 원본 식별 체크섬이 없습니다. 제작자가 지정한 지역판·버전·헤더 상태를 확인하세요.
- PPF는 검사 블록이나 복원 데이터가 패치에 포함되어 있을 때 검사합니다. PPF2의 원본 크기도 확인합니다.
- xdelta는 내장 공식 xdelta3 3.2.0을 사용하며, 패치에 포함된 체크섬과 armor 검증을 유지합니다. 검증 정보가 없는 패치는 원본 버전을 완전히 인증할 수 없습니다.

PS3 ISO에서 폴더로 변환하는 기능은 PS3_GAME을 포함한 복호화된 단일 ISO9660 이미지를 지원합니다. 암호화·분할·UDF 전용 ISO와 다른 플랫폼은 이 변환 경로에서 지원하지 않습니다.

폴더에서 ISO 생성, ISO 파일시스템 재구성, 전용 EXE 설치기 실행, 일반 덮어쓰기 ZIP 적용은 지원하지 않습니다. xdelta의 외부 압축 해제·재압축도 사용하지 않으므로 원본 데이터 파일을 선택하세요.

PPF는 기존 파일 범위 안의 수정 레코드를 지원합니다. 기본 파일 패치의 크기 한도는 128GB입니다. 게임 폴더 전체 사본과 임시 파일·백업을 저장할 충분한 여유 공간을 확보하세요. 작업 중 원본과 패치 파일을 변경하거나 이동하지 마세요.

배포 안내

프로그램 ZIP과 게임별 패치 파일을 각각 별도로 배포할 수 있습니다. 프로그램과 패치 파일을 같은 폴더에 둘 필요는 없습니다.

ZIP에는 실행 파일, 사용 설명서, 제3자 구성요소 라이선스, SHA-256 체크섬 목록이 들어 있습니다. 게임별 호환성과 알려진 번역 문제는 각 패치의 배포 안내를 확인하세요.

라이선스와 출처

Python, Tcl/Tk, PyInstaller, xdelta3와 그 구성요소의 라이선스·출처는 배포 ZIP의 licenses 폴더를 확인하세요.

내장 xdelta3는 공식 v3.2.0 릴리스 (https://github.com/jmacd/xdelta/releases/tag/v3.2.0)의 Windows x86_64 바이너리를 사용합니다.
